<h2>Student API - PATCH</h2>

<h3> Description</h3>

<p>This branch contains the PATCH API for the student management application.</p>
<P>The API allows part of a student record to be updated without replacing the whole object.</P>


<h3>Features</h3>

<p>Partially update a student record</p>

<h3> Route</h3>

<p>Update a student record by inputing the updated version in the "body" using thunder client. run https://localhost:300/students/ the id of student you want to update and click on "send"</p>
